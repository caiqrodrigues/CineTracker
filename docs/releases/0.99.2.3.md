# CineTracker Android 0.99.2.3

## Objetivo

Publicar a correção de congelamento já implementada no runtime 0.99.2 FIX2 como uma identidade Android explícita **0.99.2.3**, conforme solicitado.

Esta publicação não cria um novo runtime Web: o APK continua embarcando a pilha 0.99.2 FIX2, incluindo `patch-v096-v0992-unfreeze.js`, que elimina o ciclo recursivo de `MutationObserver -> textContent -> MutationObserver` responsável pelo travamento completo observado na WebView.

## Runtime preservado

O APK continua contendo:
- navegação autoritativa Home / Descobrir / Perfil / Configurações;
- Perfil consolidado 0.99.1;
- Home Séries/Filmes 0.99.2;
- compatibilidade de detalhe e recomendação;
- hardening de escritas pessoais;
- anti-freeze `patch-v096-v0992-unfreeze.js` com marker `fix2-idempotent-dom-mutation-guard`.

## Publicação

A release só deve ser considerada publicada depois de o workflow confirmar build Web, preparo do runtime embutido, smoke JavaScript inline, `aapt`, assinatura com `apksigner`, artifact, SHA-256 e GitHub Release.

Validação funcional em aparelho real continua sendo um estado separado da publicação técnica.
