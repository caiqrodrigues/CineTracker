# CineTracker 0.0.99 — Release Note

Data: 2026-08-26

## Escopo

A 0.0.99 reformula o Perfil Web/Android para funcionar como biblioteca pessoal reativa, com quatro carrosséis, favoritos, grids completos e ordenação LRU baseada em `last_watched_at` persistido no Supabase.

## Perfil

Abaixo das estatísticas principais:

1. Séries;
2. Séries favoritas;
3. Filmes;
4. Filmes favoritos.

Cards usam pôster 2:3, título, progresso (`18/20`, contagem de episódios ou `Visto ✓`), badge `♥` e última atividade. Todos os cards são clicáveis: TMDB oficial abre o detalhe existente; surrogate negativo abre detalhe local seguro.

## LRU e sincronização

A RPC `cinetracker_profile_media_dashboard()` consolida `watch_history`, `episode_progress` e `media_overrides` e ordena por `last_watched_at DESC`.

Ao gravar histórico, progresso ou overrides, o Perfil refaz a leitura central. Eventos da aplicação, foco/visibilidade e reconciliação periódica funcionam em conjunto para manter a UI alinhada ao banco.

## Subtelas

### Séries

### Filmes

### Favoritos
