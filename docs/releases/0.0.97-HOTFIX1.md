# CineTracker 0.0.97 HOTFIX 1

## Objetivo

Recuperar a autenticação funcional da primeira v0.0.97 sem manter a cadeia de FIX 1–7 no runtime.

## Causa reproduzida

O login autenticava no Supabase, mas a Home só era renderizada depois de `loadCloudState()` e `primeOfficialSuggestions()`. Se banco ou TMDB ficassem pendurados, o usuário permanecia na tela de login apesar da sessão válida.

## Correção

- Login válido passa a abrir a Home imediatamente.
- Hidratação de banco e recomendações ocorre em segundo plano e possui timeout próprio.
- Restauração de sessão segue a mesma regra: sessão válida → Home → hidratação.
- `authRequest` e restauração têm timeout de 8 segundos.
- Falha de persistência em `localStorage` não invalida a sessão que já está válida em memória.
- Duplo submit é bloqueado.
- Credenciais inválidas preservam e-mail/senha e reabilitam o botão.
- FIX 7 e preboot FIX 7 deixam de participar do build e do Android.
- Android usa `WebSettings.LOAD_DEFAULT`, sem `LOAD_NO_CACHE`, `authrev` ou injeção dos hotfixes antigos.
- Service Worker Web rotacionado para `ct-web-0.0.97-hotfix1`.

## Android autocontido

Para impedir que um deploy atrasado ou um cache antigo da Vercel faça o APK executar a autenticação anterior, o HOTFIX 1 empacota dentro do próprio APK o build Web já validado. O Android abre esse conteúdo por HTTPS local seguro usando `WebViewAssetLoader` em `appassets.androidplatform.net`.

Assim, o fluxo de autenticação corrigido do APK não depende de `mycinetracker.vercel.app` estar atualizado. Supabase, TMDB e demais serviços externos continuam sendo acessados normalmente pela rede.

O CI abre o APK como arquivo ZIP e confirma que `assets/hotfix1/index.html` contém `window.__ctAuthRecovery = 'v97-base'`, contém o marcador de versão HOTFIX 1 e não contém o FIX 7.

## Testes exigidos

A suíte de regressão cobre:

- banco pendurado;
- TMDB/recomendações pendurados;
- timeout de autenticação;
- storage indisponível;
- credencial inválida sem apagar os campos;
- duplo toque no botão Entrar;
- restauração de sessão;
- Home renderizada antes da hidratação;
- ausência dos FIX 1–7 no runtime de autenticação;
- build Web;
- build Android;
- Web recuperada realmente embutida no APK;
- assinatura e package Android;
- `versionCode 979`;
- `versionName 0.0.97 HOTFIX 1`.

## Deploy Web

O site Web continua sendo publicado pela Vercel quando houver capacidade de deployment disponível. Um eventual atraso da Vercel não impede o funcionamento do APK HOTFIX 1, pois o runtime Web corrigido está empacotado no aplicativo Android.
