# CineTracker Android 0.0.74

Build oficial criada sobre a linha corrigida derivada da base estável 0.0.71, usando 0.0.74 para evitar conflito com as versões 0.0.72/0.0.73 anteriormente descartadas.

- gráfico do Perfil controlado por uma única camada e posicionado imediatamente acima de Histórico;
- `ct52` permanece fora do runtime ativo para evitar disputa pelo gráfico;
- Descobrir exclui por TMDB ID e título tudo que já esteja visto, concluído, em progresso, acompanhado, Watchlist/Watch Later ou com estado persistido;
- Home/Continuar assistindo estabilizado sem observer permanente;
- Assistir mantém Carrossel/Grade/Lista dentro de `Exibição`, próximo episódio maior e botão `Assistido` centralizado;
- carregamento resiliente de episódios e notas individuais preservado;
- runtime e rodapé de Configurações alinhados para 0.0.74;
- `versionCode 74`, `versionName 0.0.74`.

A validação visual final depende de instalação e teste no aparelho real.
