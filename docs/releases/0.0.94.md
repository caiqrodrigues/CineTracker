# CineTracker 0.0.94

Versão de correção forçada após a camada 0.0.93 não ser aplicada de forma confiável no Android.

- As correções da v94 ficam embutidas diretamente no APK em `ct82-v094.js`, sem depender do deploy Web para serem carregadas.
- Restaura as sub-abas **Pra Você** e **Calendário** com dados do TMDB.
- Padroniza altura/largura dos cards do Histórico e aplica truncamento com reticências.
- Padroniza os cards de episódios mantendo thumbnail, nota, data e sinopse.
- Restaura o **Gráfico de Consumo** no Perfil.
- Mantém Episódios e Filmes lado a lado na primeira fileira do Perfil.
- Remove apenas as métricas Gostei, Não Gostei e Ver Depois do Perfil.
- Separa Séries na Watchlist e Filmes na Watchlist.
- Preserva os dois carrosséis da filmografia do ator, ordenados do mais recente para o mais antigo.
- Atualiza Web e Android para **v94 / 0.0.94**.
