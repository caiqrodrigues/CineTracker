# CineTracker Android 0.0.59

Correções solicitadas para consistência de séries, Descobrir e Perfil.

## Alterações

- Botões que avançam o próximo episódio passam a exibir **Assistido** em vez de **Próximo episódio**.
- Cards de séries passam a mostrar **Faltam X episódios** junto do progresso, incluindo Home, Assistir e detalhes quando houver dados de progresso.
- Descobrir passa a ocultar títulos que já fazem parte do universo do usuário: vistos/concluídos, em progresso/acompanhamento e Watchlist/Watch Later.
- Corrigido o gráfico do Perfil que era ocultado pelo patch Android anterior.
- Rodapé/indicador de versão das Configurações atualizado para **0.0.59**.
- Novo patch Android `ct49.js`, mantendo os módulos anteriores e aplicando apenas as correções desta versão.
