# CineTracker Android 0.0.55

## Objetivo

Recuperar a estabilidade da 0.0.49 sem continuar herdando a interface Web atual do Vercel.

## Mudança estrutural

A 0.0.55 não usa mais `https://mycinetracker.vercel.app` como documento principal do WebView. Durante o CI, o conteúdo exato de `apps/web` da tag `android-v0.0.49` é extraído com `git archive` e empacotado em `assets/stable49/` dentro do APK. O WebView abre `file:///android_asset/stable49/index.html`.

Supabase e TMDB continuam online. Apenas HTML/CSS/JavaScript-base ficam congelados na versão aprovada, impedindo que um deploy Web posterior altere ou quebre o Android.

## Camadas Android carregadas

- `ct41.js`
- `ct47.js`
- `ct48.js`
- `ct49.js`
- `ct54.js` como camada pequena de correções, reportando build 0.0.55.

Não são carregados os runtimes regressivos 0.0.50–0.0.53.

## Correções mantidas

- Continuar assistindo horizontal/rolável.
- Clique em série do Home direcionado à ficha da série.
- Marcação inteligente: ao marcar episódio posterior, perguntar se os anteriores da temporada já foram vistos.
- Botão Voltar tenta retornar dentro da navegação do app antes de sair.
- Descobrir reforçado para três colunas compactas.
- Acompanhando reordenado pela atividade mais recente quando o RPC de atividade estiver disponível.
- Onde assistir: streaming, aluguel, compra e estreia de cinema no Brasil quando disponíveis via TMDB.
- Notificações nativas preservadas.

## Validação automatizada

O CI deve validar:

1. existência da tag `android-v0.0.49`;
2. empacotamento real de `assets/stable49/index.html`;
3. sintaxe dos módulos Android;
4. compilação Gradle;
5. package `com.cinetracker.app`;
6. presença do snapshot 0.0.49 dentro do APK;
7. publicação da Release.

## Limitação de validação

Build e empacotamento não equivalem a teste funcional em aparelho. A versão só deve ser marcada como validada visualmente após teste real do usuário em Android.
