# CineTracker Android 0.0.56

## Base preservada

Esta versão parte diretamente da estrutura restaurada da **0.0.48**. A arquitetura Android não foi alterada: o WebView continua carregando a aplicação Web configurada e injeta somente os módulos já existentes `ct41.js`, `ct47.js` e `ct48.js`. Não foram adicionados runtimes `ct49+` nem foi alterada a estrutura de navegação do projeto.

## Correções pontuais

- Marcação inteligente de episódio: ao marcar um episódio acima do primeiro, pergunta se os episódios anteriores da mesma temporada também já foram assistidos; se confirmado, grava a sequência automaticamente.
- Home > Continuar assistindo passa a usar a mesma origem de dados de `Acompanhando` (`cinetracker_continue_items_v2`, status `following`).
- Continuar assistindo recebe rolagem horizontal real, abertura da série e botão para marcar o próximo episódio como visto.
- Assistir > Acompanhando recebe botão de check para marcar o próximo episódio como visto.
- Acompanhando é reordenado pela atividade mais recente (`last_watched_at` / `updated_at`), trazendo para o início a série cujo episódio foi visto por último.
- Descobrir é reforçado para três cards por linha no layout Android compacto.
- Ao marcar episódio ou filme como visto, o estado em nuvem é recarregado para que Perfil/estatísticas reflitam a alteração na próxima renderização imediatamente.
- Detalhes de filmes e séries passam a exibir disponibilidade no Brasil via provedores TMDB: streaming, aluguel, compra e, para filmes, data de cinema quando disponível.
- O comportamento de navegação interna continua baseado na estrutura da 0.0.48.

## Validação automatizada

O CI valida que somente `ct41.js`, `ct47.js` e `ct48.js` compõem a camada Android e rejeita a build caso `ct49.js` exista. Também valida sintaxe JavaScript, compilação Gradle, `applicationId=com.cinetracker.app` e `versionName=0.0.56` antes da publicação.

## Estado de validação

A compilação automatizada não equivale a teste funcional em aparelho. As correções permanecem pendentes de validação visual/funcional no dispositivo Android após instalação.
