# CineTracker Android 0.0.45

## Objetivo da versão

A 0.0.45 elimina o modelo de build que reescrevia `MainActivity.java` durante o GitHub Actions e acumulava patches Android de várias versões. A partir desta versão, o código Java presente no repositório é o mesmo código compilado no APK.

## Alterações principais

### Assistir

- Carrossel é o modo de visualização padrão.
- Modos disponíveis: Carrossel, Grade e Lista.
- Séries são organizadas nesta ordem física:
  1. Em dia
  2. Acompanhando
  3. Juntando poeira
  4. Não iniciadas
- Ao abrir Assistir > Séries, a tela posiciona automaticamente a seção Acompanhando, permitindo rolar para cima e encontrar Em dia e para baixo encontrar Juntando poeira e Não iniciadas.
- Cards de filmes e séries são clicáveis.
- Série abre tela de detalhes.
- Temporadas podem ser expandidas.
- Episódios podem ser abertos individualmente.
- Episódios podem ser marcados/desmarcados como assistidos.
- Estado de episódio é persistido via Supabase.

### Descobrir

- Grades de Descobrir usam três cards por linha no Android.
- Posters e textos foram compactados para caber corretamente em telas de celular.
- A regra vale para os diferentes filtros/abas que renderizam a grade padrão de Descobrir.

### Perfil / Tempo de Tela

- Gráficos antigos de atividade por horário são removidos/ocultados da experiência Android.
- O gráfico diário permanece no tema dark do sistema.
- O foco é a navegação diária do histórico de episódios.

## Arquitetura Android

Antes da 0.0.45, o workflow alterava `MainActivity.java` em tempo de build e injetava patches sequenciais (`ct33`, `ct34`, ..., `ct44`). Isso dificultava garantir que o APK publicado refletia exatamente o código do repositório.

Na 0.0.45:

- `MainActivity.java` já contém a versão real 0.0.45.
- O workflow apenas compila e publica o código existente.
- O módulo final Android é `apps/android/app/src/main/assets/ct45.js`.
- Patches conflitantes 0.0.40/0.0.42/0.0.44 não são mais carregados pela Activity.
- O APK usa `versionCode 45` e `versionName 0.0.45`.

## Backend

A marcação manual de episódios usa as funções RPC:

- `cinetracker_episode_state`
- `cinetracker_set_episode_watched`

Essas funções trabalham com `episode_progress`, vinculando o TMDB ID da série à mídia persistida do usuário.

## Build e Release

Workflow: `.github/workflows/build-android.yml`

Artefato esperado:

`cinetracker-android-0.0.45-debug.apk`

Release esperada:

`android-v0.0.45`

## Validação

Compilação bem-sucedida no GitHub Actions não significa validação visual/funcional. A versão só deve ser marcada como validada após instalação real no Android e confirmação do comportamento pelo usuário.
