# CineTracker Android 0.0.77

Atualização de paridade Web/Android e pré-carregamento.

- pré-carregamento de dados e imagens sem navegar automaticamente entre abas;
- cache e deduplicação de leituras para evitar carregamento repetido;
- padrão global para séries em cards e detalhes: `Temporada X • Episódio Y • vistos/total • Faltam N episódios`;
- módulo `ct62.js` aplica o progresso em todas as áreas Android que exibem séries;
- build 77 e APK publicados pelo workflow `Verify`.

A validação visual final depende de instalação em aparelho real.
