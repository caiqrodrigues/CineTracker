# CineTracker Android 0.0.88

- Corrige roteamento global entre Home, Descobrir, Histórico, Perfil e Configurações.
- Mantém cliques globais de filmes, séries e episódios abrindo seus detalhes.
- Mantém Home unificada com Grade, Carrossel, Lista e filtros de status.
- Mantém Descobrir com streaming, elenco, ator e filmografia clicável e exclusões de vistos/watchlist/acompanhados.
- Mantém Histórico clicável e Perfil reorganizado sem sub-aba Histórico.
- Adiciona gráfico de linha das notas de episódios abaixo das temporadas nas séries.
- O maior ponto da temporada fica verde, o menor vermelho e os demais em cor neutra.
- As temporadas ficam em carrossel horizontal com swipe.
- Versionamento Android atualizado para 0.0.88. Web correspondente: 0.5.8.
