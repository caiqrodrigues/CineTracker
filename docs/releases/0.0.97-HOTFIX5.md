# CineTracker 0.0.97 HOTFIX 5

## Causa confirmada

O Supabase gerenciado permaneceu saudável e aceitando autenticação. Em dispositivo físico, as versões Android 0.0.94 e 0.0.95 receberam HTTP 200 no endpoint de login. O problema estava no runtime do cliente e no desalinhamento entre APK, GitHub e Web publicada.

A linha 0.0.95 no `main` também estava 135 commits atrás da linha já recuperada pelo HOTFIX 2. Além disso, versões antigas do Android ainda podiam depender da Web remota, e o HOTFIX 2 mantinha um fallback automático para Vercel após um watchdog curto.

## HOTFIX 5

- Parte da linha validada do HOTFIX 2, não do `main` antigo 0.0.95.
- Mantém o Web runtime completo embutido no APK.
- Usa `WebView.loadDataWithBaseURL` com a origem HTTPS histórica apenas para preservar `localStorage` e cookies.
- Remove totalmente o fallback automático de inicialização para Vercel.
- Intercepta navegação principal para `mycinetracker.vercel.app` e recarrega o bundle interno em vez de trocar o runtime do APK.
- Falha de leitura do bundle mostra uma tela de diagnóstico local; não baixa outra versão silenciosamente.
- Mantém Service Worker desativado dentro do bundle Android.
- Login válido abre a Home antes da hidratação de banco/TMDB.
- Login e refresh usam cabeçalhos próprios e não herdam um `Authorization` antigo ou malformado.
- Sessões restauradas validam a estrutura do JWT.
- Se o access token local estiver inválido mas houver refresh token, o app tenta renovar a sessão antes de descartá-la.
- Uma falha de `/auth/v1/user` tenta um refresh único antes de encerrar a sessão.
- Sessão Web válida é enviada novamente à ponte nativa para manter o worker Android sincronizado.
- FIX 7 e preboot FIX 7 continuam excluídos do runtime recuperado.

## Vercel

Vercel volta a ser destino da versão Web, mas deixa de ser dependência de boot do APK. Assim, atraso, cache, build rate limit ou deploy quebrado da Web não pode trocar o código executado pelo HOTFIX 5 no Android.

## Validações obrigatórias de CI

- `npm run verify`.
- build Web completo.
- suíte de regressão de autenticação.
- marcador `window.__ctAuthRecovery = 'v97-hotfix5'`.
- validação `ctLooksLikeJwt` presente.
- ausência de FIX 7.
- bundle Android autocontido e com scripts locais inlined.
- ausência de `WebViewAssetLoader` e `appassets.androidplatform.net`.
- ausência de `loadRemoteFallback`, `fallback=remote` e watchdog remoto.
- presença de `loadDataWithBaseURL` e `hotfix5/index.html`.
- APK contém o runtime HOTFIX 5 validado.
- assinatura e package `com.cinetracker.app`.
- `versionCode 983`.
- `versionName 0.0.97 HOTFIX 5`.
