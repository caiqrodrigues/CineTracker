# CineTracker Web 0.5.7

Versão focada exclusivamente em arquitetura, cache e pré-carregamento, sem alterações de layout ou funcionalidades visíveis em relação à 0.5.6.

- mantém integralmente a interface e os fluxos aprovados da 0.5.6;
- adiciona IndexedDB para snapshots locais de continuar assistindo, histórico, overrides e perfil;
- adiciona Service Worker para cache persistente de capas e metadados TMDB;
- usa cache-first para imagens TMDB e stale-while-revalidate para metadados TMDB;
- pré-carrega silenciosamente capas já conhecidas da biblioteca;
- preserva Supabase como fonte consolidada do estado do usuário;
- mantém atualização de dados em segundo plano, sem bloquear a renderização das telas;
- evita refazer downloads de capas/metadados já disponíveis no cache;
- prepara a base para abertura e troca de abas mais rápidas sem alterar comportamento funcional.

Objetivo da versão: abrir com conteúdo já disponível localmente sempre que possível, reduzir loading perceptível e deixar navegação mais fluida.
