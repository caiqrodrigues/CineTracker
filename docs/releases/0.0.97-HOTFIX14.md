# CineTracker 0.0.97 HOTFIX 14

HOTFIX14 corrige os três problemas reproduzidos em aparelho real após o HOTFIX13, sem reativar a camada global v97 e sem resetar dados do usuário.

## Web desktop

- A navegação agora confirma que a tela de destino realmente foi renderizada, em vez de considerar apenas o retorno da função de roteamento.
- Início, Descobrir, Histórico, Perfil e Configurações são exercitados por cliques reais no navegador no CI.
- A antiga camada HOTFIX12 de captura global de cliques foi removida do runtime final; ela podia interceptar o evento antes das correções posteriores.
- O novo arquivo de runtime possui nome próprio (`patch-v084-hotfix14-real-device.js`), evitando reutilização de um script de navegação antigo em cache.

## Web no celular

- O fluxo com `library.csv` + `watches.csv` mantém o primeiro arquivo ao voltar do seletor, mantém o segundo seletor e executa prévia, confirmação, importação e sincronização.
- O teste mobile real-browser confirma `begin -> library_batch -> watches_batch -> finish` e recarregamento do estado cloud após a conclusão.
- A semântica Bingers do HOTFIX13 é preservada, inclusive `plays`, Watchlist de séries não iniciadas, InProgress e WatchLater.

## Android físico

O erro observado no aparelho acontecia quando o Android recriava a Activity/WebView enquanto o seletor de arquivos estava aberto. Nesse cenário, o callback JavaScript do `<input type=file>` podia desaparecer e o HOTFIX13 descartava o resultado ao retornar.

HOTFIX14 altera esse fluxo:

- o slot selecionado (`library`, `watches` ou pacote) é persistido no lado nativo antes de abrir o seletor;
- o arquivo retornado é copiado para armazenamento privado temporário do CineTracker;
- nome, MIME type e bytes sobrevivem à recriação da Activity/WebView;
- quando o runtime volta a carregar, o arquivo é reconstruído e reinserido automaticamente no estado do importador;
- o callback WebView antigo continua suportado quando ele ainda existe;
- os arquivos temporários são removidos depois de uma importação concluída.

## Arquitetura preservada

- núcleo funcional v95 continua ativo;
- overlay global v97 continua desativado;
- Android continua totalmente embutido no APK em `assets/hotfix5/index.html`;
- continua usando `loadDataWithBaseURL`;
- sem WebViewAssetLoader;
- sem fallback remoto para Vercel;
- autenticação/session recovery HOTFIX7+ preservados;
- nenhuma limpeza geral de banco, biblioteca, preferências ou decisões manuais.

## Bingers

HOTFIX14 mantém integralmente as correções do HOTFIX13:

- `plays` preserva reprises;
- séries sem episódios assistidos ficam como não iniciadas/Watchlist;
- séries com histórico ficam InProgress;
- `for_later` permanece WatchLater;
- histórico identificável não é descartado silenciosamente;
- ratings, comentários, avaliações e `lists.csv` continuam ignorados;
- decisões manuais continuam tendo prioridade.
