# CineTracker 0.0.98 — Release Note

Data: 2026-08-26

## Escopo

A 0.0.98 consolidou a navegação principal em Home, Descobrir, Perfil e Configurações; removeu Histórico como aba independente e integrou seu conteúdo ao Perfil; reformulou Descobrir; consolidou Backup & Restauração em Exportar/Importar; implementou backup ZIP/CSV autenticado; e corrigiu ações de Cache/Metadados.

## Principais mudanças

- gate de navegação `patch-v088-v098-nav-pre.js`;
- UI 0.0.98 `patch-v089-v098.js`;
- compatibilidade `patch-v090-v098-compat.js`;
- Perfil com estatísticas, gráfico, extras e histórico integrado;
- RPC `cinetracker_profile_history_media(integer)`;
- Descobrir: Pra você, Em alta, Mais aguardados, Mais bem avaliados, Calendário;
- filtros Todos/Filmes/Séries e ranking decrescente;
- Backup & Restauração com somente Exportar/Importar;
- ZIP com CSVs de conta;
- Edge Function `ct-backup-user` v1;
- Limpar Cache e Atualizar Metadados funcionais;
- Web package/cache `0.0.98` / `ct-web-0.0.98`;
- Android `versionName 0.0.98`, `versionCode 996`.

## Continuidade

A 0.0.99 sucede esta release e adiciona a biblioteca pessoal reativa/LRU no Perfil. Esta nota foi adicionada retroativamente para fechar a pendência documental da 0.0.98, sem afirmar publicação Android não comprovada.
