# CineTracker 0.0.97 HOTFIX 10

Selective recovery on top of the stable HOTFIX9/v95 core. No database rollback and no user-data reset.

## Restored safely
- Five primary views: Home, Discover, History, Profile and Settings.
- Discover opens on **Pra Você** and keeps **Calendário** last.
- Pra Você preserves the v95 seven-slot model, year > 1990 and rating >= 7.8.
- Pra Você actions use the current database schema and are recorded as manual decisions.
- Bingers import accepts ZIP, JSON or `library.csv` + `watches.csv`.
- Import always shows a preview before confirmation.

## Import integrity
- Re-import deletes only rows created by an earlier Bingers import.
- Native CineTracker watch history is not deleted.
- Manual media overrides are never replaced by imported overrides.
- Imported episode progress ignores conflicts with existing progress.
- Recommendation history and daily menus are not cleared by import.

## Stability strategy
- `patch-v068-v097.js` remains disabled.
- No global MutationObserver or periodic polling layer was restored.
- HOTFIX10 is composed from small selective patches on top of the proven v95 core.
- Android remains an authoritative embedded runtime with no automatic Vercel fallback.
- The Android native navigation compatibility bridge enters the same HOTFIX10 router without changing the stable Java navigation infrastructure.

## Validation gates
- Login/startup recovery regression suite.
- Real Chrome changes to every target view, not only a visible shell check.
- Pra Você first / Calendário last assertion.
- Assistido and Watchlist writes validated against mocked current-schema requests.
- Two real CSV files loaded into the browser; preview validated before any import API call.
- Exact embedded Android HTML repeats the same browser tests.
- Every Android inline script syntax-compiled.
- APK package, version, signature and embedded HOTFIX10 markers verified before release.
