# CineTracker Android 0.0.75

Base: Android 0.0.74, com uma única alteração funcional nesta etapa.

## Correção

- Pré-carregamento das abas do aplicativo na abertura.
- O WebView fica oculto enquanto Home, Assistir, Descobrir, Histórico, Perfil e Configurações são aquecidos em segundo plano.
- Requisições somente de leitura do Supabase/TMDB usadas durante o aquecimento são mantidas em cache temporário para que a primeira abertura das abas reutilize os dados já buscados.
- Ao terminar o aquecimento, o aplicativo retorna para Home e libera a interface para uso.
- Existe fallback nativo de 10 segundos para impedir que o aplicativo permaneça invisível caso o pré-carregamento falhe.

## Versão

- versionCode: 75
- versionName: 0.0.75

Esta versão não tenta corrigir outros problemas visuais ou funcionais; o objetivo é validar somente o carregamento antecipado das abas.
