# CineTracker Android 0.0.62

## Corrigido

- Gráfico diário do Perfil passa a ser auto-recuperável após rerenders e trocas de aba.
- Botões `Assistido` ficam neutros/apagados por padrão e usam verde somente para estado efetivamente assistido.
- Estado de filmes/séries já vistos é reconciliado com `media_overrides` (`AlreadySeen`/`Completed`).
- Estado de episódios continua seguindo a marcação persistente.
- Metadados de `Continuar assistindo` são normalizados para impedir concatenação/repetição visual observada na 0.0.61.
- Indicadores de `Carregando detalhes...`/`Carregando histórico...` fora do contexto correto são removidos.

## Preservado

- Descobrir estrito por ID TMDB e título normalizado.
- Deduplicação de provedores de streaming por família do serviço.
- Padrão visual de detalhes, notas e disponibilidade.

## Versão

- `versionCode`: 62
- `versionName`: `0.0.62`
- Runtime adicional: `ct52.js`

Esta release não deve ser marcada como validada apenas pela compilação. Confirmar em aparelho real: gráfico após múltiplas navegações, estados dos botões, continuidade sem texto corrompido, ausência de loaders presos e regressões em Descobrir/streaming.
