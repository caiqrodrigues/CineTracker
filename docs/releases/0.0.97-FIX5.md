# CineTracker 0.0.97 FIX 5

- Remove a causa do login infinito: FIX 3 e FIX 4 deixam de ser carregados pelo build web e deixam de ser injetados pelo Android.
- O FIX 5 passa a ser o único dono do fluxo de autenticação no Android.
- O WebView usa `LOAD_NO_CACHE`, limpa o cache anterior e abre a revisão `fix=5&authrev=5`, evitando executar JavaScript antigo com cache imutável.
- Após resposta 200 do Supabase, a sessão é aplicada via `saveSession()`, `ctSession` e `currentUser`, a view muda para `home` e `render()` precisa remover o formulário de login e criar a aplicação; caso contrário, o login é tratado como falha.
- A sincronização do banco e as recomendações continuam em segundo plano e não bloqueiam a entrada na Home.
- O Android injeta apenas `ct87-v097-fix5.js` como hotfix de autenticação; `ct85-v097-fix.js` e `ct86-v097-fix4.js` ficam fora da cadeia de execução.
- `versionCode` passa para `975` para garantir atualização limpa sobre os APKs FIX anteriores.
- Teste de regressão executa 25 ciclos completos de autenticação em runtime JavaScript e exige: uma única chamada de login, sessão persistida, `currentUser`, `ctSession`, `view=home`, `.app` presente e `#auth-form` ausente.
- CI também valida sintaxe, build web, build Gradle, módulo embarcado, assinatura do APK, package name, versionName e versionCode.
