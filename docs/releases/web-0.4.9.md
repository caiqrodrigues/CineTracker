# CineTracker Web 0.4.9

## Correções

- Home > Continuar assistindo passa a usar a mesma classificação de Acompanhando da aba Assistir.
- Continuar assistindo e Acompanhando recebem botão de check para marcar o próximo episódio como assistido.
- A marcação persiste pelo mesmo backend Supabase usado no Android.
- Descobrir força três cards por linha nos contêineres reais de mídia, inclusive em larguras móveis.

## Paridade
