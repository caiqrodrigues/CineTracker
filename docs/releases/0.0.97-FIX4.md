# CineTracker 0.0.97 FIX 4

- Corrige a corrida entre o submit legado da tela de login e o hotfix Android, que podia recriar/limpar o formulário sem concluir a entrada.
- O FIX 4 intercepta o submit na fase de captura e bloqueia os handlers antigos antes que eles sejam executados.
- Após autenticação 200 do Supabase, usa o `saveSession()` base para atualizar `ctSession`, `currentUser` e `localStorage` no mesmo contexto da aplicação.
- A tela principal é aberta imediatamente após a sessão válida, sem `location.reload()`.
- Sincronização do banco e recomendações passam a hidratar em segundo plano, sem bloquear a entrada.
- O Android injeta `ct86-v097-fix4.js` por último, acima dos FIX anteriores.
- Testes obrigatórios no CI: sintaxe dos módulos, regressão específica de autenticação FIX 4, build Gradle, comparação do módulo embarcado, assinatura do APK, package name e versão.
- Release separada: `android-v0.0.97-fix4`.
