# CineTracker 1.0.0 — Release oficial

**Data:** 2026-09-04  
**Status:** oficial  
**Plataformas:** Web + Android  
**Backend:** Supabase production compartilhado

## Objetivo

A 1.0.0 transforma o estado funcional consolidado do CineTracker na primeira baseline oficial do projeto. O objetivo desta release não é adicionar outra camada de comportamento, mas congelar, numerar, validar e documentar o sistema que foi aceito na Web e no Android.

### Correção bloqueadora incorporada

A 0.99.7.71 resolveu o último bloqueador antes da 1.0.0. O renderer ativo `ct186` podia exibir um card da Watchlist escolhido a partir do pool selecionado/fallback, enquanto `pool237()` reconstruía outra lista. O botão podia estar visível e não encontrar um próximo item.

A solução final faz o handler usar exatamente o pool já escolhido pelo renderer:

- `watchlist:movie` → `wmPool`;
- `watchlist:series` → `wsPool`;
- `watchlist:anime` → `waPool`.

O usuário confirmou a correção no aparelho. A 1.0.0 mantém esse runtime sem nova lógica de gesto.

### Scroll Top 10 / streamings

O usuário também confirmou o scroll lateral corrigido. A baseline 1.0.0 preserva scroll horizontal nativo do WebView e proíbe reintroduzir `touchstart/touchmove` manual para esses trilhos.
