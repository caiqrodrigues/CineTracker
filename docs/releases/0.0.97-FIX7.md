# CineTracker 0.0.97 FIX 7

## Correção estrutural da autenticação

- O bootstrap legado do `index.html` não é mais executado no build. Ele é explicitamente diferido para impedir a corrida `restoreSession -> loadCloudState -> primeOfficialSuggestions -> render` que podia redesenhar a tela de login depois de uma autenticação HTTP 200.
- O FIX 7 é o único bootstrap de autenticação e o único dono do submit/login no Web e Android.
- Login tem timeout estrito de 8 segundos com `AbortController`.
- O caminho crítico após HTTP 200 foi reduzido para: aplicar `ctSession/currentUser` em memória -> selecionar `view=home` -> `render()` -> confirmar que `#auth-form` desapareceu -> liberar loading.
- Persistência em storage e hidratação de banco/recomendações acontecem somente depois da Home, fora do caminho crítico.
- Falha de `localStorage` é isolada por `try/catch` e não impede a sessão em memória nem a abertura da Home.
- O listener de estado de autenticação é singleton e possui cleanup explícito.

## Cadastro restaurado

- `Criar conta` volta a chamar `/auth/v1/signup` com timeout de 8 segundos.
- Se o Supabase retornar sessão imediatamente, o usuário entra na Home.
- Se confirmação de e-mail estiver habilitada, a interface retorna para Entrar e informa que a conta foi criada e precisa ser confirmada.
- Foi removida a mensagem `Cadastro temporariamente indisponível neste hotfix`.

## Android

- `versionCode 977` / `versionName 0.0.97 FIX 7`.
- WebView usa `fix=7&authrev=7`, `LOAD_NO_CACHE` e limpeza do cache anterior.
- Somente `ct89-v097-fix7.js` é injetado como hotfix de autenticação; FIX 6 não é executado.
- Nenhuma chamada de bridge Android/WorkManager faz parte do caminho crítico antes da Home.

## Evidência e testes

- Logs reais do Supabase confirmaram que a conta oficial retorna HTTP 200 em `/auth/v1/token`; o defeito estava no pós-login do aplicativo.
- Stress suite executa 500 logins consecutivos em runtime JavaScript e exige uma única requisição, `ctSession`, `currentUser`, `view=home`, Home renderizada e `isLoading=false`.
- Teste força falha de `localStorage` e exige que a Home continue abrindo sem crash.
- Teste força timeout e exige aborto, mensagem clara e botão liberado.
- Testes cobrem signup com sessão imediata e signup que exige confirmação de e-mail.
- Build Web verifica que `void bootstrap();` não existe no HTML final e que o bootstrap legado ficou diferido.
- CI valida sintaxe, build Web, build Gradle, asset FIX 7 realmente embarcado, assinatura, package, versionName e versionCode.
