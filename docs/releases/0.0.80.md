# CineTracker Android 0.0.80

Release de estabilização do ciclo principal do aplicativo.

- reduz o runtime Android injetado aos módulos realmente ativos (`ct47.js` + `ct65.js`);
- remove a cadeia de patches Android concorrentes que provocava loops e múltiplos refreshes;
- pré-carrega o universo principal com orçamento curto e sem bloquear indefinidamente a interface;
- navegação nativa passa por uma única rota (`ct65Navigate`);
- após marcar episódio, o estado principal é relido e o progresso é atualizado;
- Configurações exibe uma única versão oficial: `0.0.80`;
- histórico não recebe linhas adicionais de progresso;
- Perfil recompõe o gráfico de atividade acima do Histórico;
- Descobrir usa o universo conhecido (histórico, acompanhamento e Watchlist/overrides) para ocultar itens já conhecidos.

Objetivo desta release: `abre → dados aparecem → navega → marca episódio → sincroniza → reabre mantendo o estado`.

Validação automatizada final: Web 0.5.1 + Android 0.0.80.

A validação visual final ainda depende de instalação e teste no aparelho.
