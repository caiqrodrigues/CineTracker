# CineTracker 0.0.97 HOTFIX 12

## Correções principais

- Corrige a navegação Web desktop quando apenas **Início** e **Descobrir** respondiam.
- Adiciona um pre-router de navegação carregado antes da camada seletiva HOTFIX10 para garantir clique funcional em **Início, Descobrir, Histórico, Perfil e Configurações**.
- Corrige o fluxo de importação no navegador mobile em que, ao selecionar o primeiro CSV, o retorno do seletor de arquivos disparava `focus`/`visibilitychange`, sincronização cloud e `render()`, reconstruindo Configurações e removendo o segundo seletor.
- Mantém `library.csv` e `watches.csv` em estado persistente durante o fluxo de seleção, inclusive se o painel precisar ser refeito.
- Mantém a prévia obrigatória antes de qualquer escrita.
- Mantém importação e sincronização pelo mesmo Supabase da conta autenticada entre Web e Android.
- Continua aceitando CSV com vírgula, ponto-e-vírgula, tabulação e BOM UTF-8.
- Mantém ZIP/JSON como alternativa ao par de CSVs.

## Estabilidade preservada

- Runtime principal continua baseado no núcleo estável v0.0.95.
- Overlay global v97 continua fora do HTML distribuído.
- Auth/login-first, timeout de restauração, validação JWT e reset único de sessão potencialmente corrompida continuam preservados.
- Nenhum rollback de banco, histórico, biblioteca ou preferências do usuário.
- Android continua usando runtime HTML/JS autocontido dentro do APK com `loadDataWithBaseURL`, sem WebViewAssetLoader e sem fallback remoto automático.

## Validação obrigatória

A release só é publicada após testes automatizados em Chrome real cobrindo:

- navegação desktop real por todas as abas principais;
- viewport mobile 390×844;
- seleção de `library.csv`;
- simulação do retorno do seletor nativo com `focus`/`visibilitychange`;
- permanência do painel e do segundo seletor;
- seleção de `watches.csv`;
- prévia antes de escrita;
- sequência do backend `begin → library_batch → watches_batch → finish`;
- recarga do estado cloud após importação;
- repetição do mesmo fluxo contra o HTML exato embutido no Android;
- compilação de todos os scripts inline do Android;
- assinatura, package id e identidade do APK.
