# CineTracker Android 0.0.83

Versão focada exclusivamente em arquitetura, cache persistente e pré-carregamento, sem alterações de layout ou funcionalidades visíveis em relação à 0.0.82.

- mantém integralmente a interface e os fluxos aprovados da 0.0.82;
- adiciona cache persistente local via IndexedDB dentro do WebView;
- mantém snapshots de continuar assistindo, histórico, overrides e perfil;
- pré-carrega silenciosamente capas já conhecidas;
- reforça a reutilização do cache do WebView e dos módulos de metadados existentes;
- mantém Supabase como fonte consolidada do estado do usuário;
- atualiza dados em segundo plano sem bloquear troca de abas;
- preserva TMDB como fonte de metadados, evitando chamadas repetidas para itens já conhecidos;
- adiciona ct69-cache.js como camada exclusiva de performance, sem DOM/layout novo.

Objetivo da versão: reduzir loading perceptível, reaproveitar dados já carregados e melhorar abertura e navegação sem qualquer mudança visual ou funcional.
