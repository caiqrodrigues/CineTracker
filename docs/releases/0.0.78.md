# CineTracker Android 0.0.78

Correções desta versão:

- elimina o looping de carregamento/re-renderização em Home e Assistir;
- impede repetição das linhas de progresso de episódios e metadados;
- padroniza séries em todo o sistema como `Temporada X • Episódio Y • vistos/total • Faltam N episódios`;
- mantém uma única linha de progresso por série;
- atualiza a versão exibida em Configurações para `0.0.78`;
- preserva o pré-carregamento sem navegação serial entre abas.

Build: `versionCode 78` / `versionName 0.0.78`.
