# CineTracker 0.0.97 FIX 3

- Corrige o fluxo de login observado no Android em que o formulário era recriado e os campos eram limpos sem concluir a entrada.
- Após resposta 200 do Supabase, a sessão é persistida em `localStorage` e no bridge nativo.
- O app reinicia o fluxo da aplicação e deixa o `bootstrap()` base restaurar a sessão no próprio escopo, evitando disputa com `ctSession/currentUser` do script injetado.
- Mantém timeout de autenticação, desbloqueio de loading e restauração de sessão.
- Mantém integralmente os recursos da v0.0.97 e dos FIX anteriores.
- Rodapé e Android exibem `0.0.97 FIX 3`.
- Release separada: `android-v0.0.97-fix3`.
