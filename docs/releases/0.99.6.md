# CineTracker 0.99.6 — Web + Android

**Data:** 2026-08-28  
**Status:** candidato em validação; não declarar publicado antes dos gates finais.

## Objetivo

Consolidar a experiência real de Web e Android depois que evidência em vídeo mostrou que a 0.99.5 ainda permitia que telas/estruturas legadas vencessem no runtime.

## Principais correções

### Perfil autoritativo

`patch-v116-v0996-authoritative.js` renderiza Perfil diretamente. Ordem final:
Séries → Filmes → Séries Favoritas → Filmes Favoritos → Atores Favoritos → Episódios por dia → Estatísticas extras.

O gráfico de atividade usa `watch_history`, contando episódios distintos por data no intervalo D-10 a D+3.

### Atores favoritos

- coração nos cards do elenco;
- favoritar/desfavoritar na página da pessoa;
- seção Atores Favoritos no Perfil;
- RLS em `favorite_actors`;
- interação do coração isolada do clique que abre a pessoa.

### Capas ausentes

`ct-enrich-media-user` v5 permite enriquecimento direcionado de cards visíveis sem pôster. O cliente envia apenas IDs visíveis; a Edge Function restringe esses IDs ao dashboard autenticado e resolve surrogates por título/ano antes de atualizar capa e metadados.

### Avaliações por temporada

O gráfico deixa de existir dentro do accordion da temporada. `patch-v117-v0996-final.js` cria uma seção independente **Avaliações dos episódios por temporada** logo após o bloco de temporadas/episódios.

- disponível com accordions abertos ou fechados;
- scroll horizontal entre temporadas;
- carregamento sob demanda;
- SxxExx no eixo X e 0–10 no Y;
- melhor episódio verde e pior vermelho;
- tooltip com código, nota, nome e votos.

### Descobrir

`patch-v116-v0996-authoritative.js` é a autoridade final de Descobrir.

- Pra Você / Em alta / Mais aguardados / Mais bem avaliados / Calendário;
- Geral / Séries / Filmes;
- exclusões de histórico/vistos/Watchlist são obrigatórias;
- falha fechada se não for possível obter exclusões autenticadas;
- aliases original/localizado bloqueiam títulos equivalentes;
- busca em múltiplas páginas amplia o pool elegível;
- slots pessoais tentam resolver imports sem ID TMDB oficial;
- Calendário usa `next_episode_to_air` para séries acompanhadas.

### Web e Android alinhados

O APK 0.99.6 incorpora o mesmo `dist` Web validado, incluindo v116 e v117.

Identidade Android:
- `applicationId com.cinetracker.app`;
- `versionName 0.99.6`;
- `versionCode 9960`;
- release alvo `android-v0.99.6`.
