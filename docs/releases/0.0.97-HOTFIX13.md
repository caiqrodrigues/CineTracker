# CineTracker 0.0.97 HOTFIX 13

HOTFIX13 corrige a semântica da importação do Bingers mantendo o núcleo estável v95 e todas as proteções de autenticação/navegação dos HOTFIX9-12.

## Importação Bingers corrigida

- `watches.csv` passa a respeitar a coluna `plays`.
- Reassistidas não são transformadas em datas fictícias: o CineTracker preserva `first_watched_at`, `last_watched_at` e `plays`.
- Séries marcadas pelo Bingers como `watching`, mas sem nenhum episódio no histórico, são classificadas como não iniciadas e adicionadas à Watchlist.
- Séries com histórico de episódios são classificadas como iniciadas/InProgress.
- `for_later` é preservado como `WatchLater` e continua disponível como item salvo/Watchlist quando aplicável.
- Registros históricos identificáveis que não estão mais na biblioteca atual recebem uma referência histórica segura em vez de serem descartados.
- Se algum registro não puder ser mapeado com segurança, a confirmação da importação é bloqueada e a prévia informa o problema.
- `ratings.csv`, notas, avaliações, comentários e `lists.csv` não são importados.

## Estatísticas

O RPC de estatísticas agora soma `external_ids.plays` para histórico importado, com fallback para registros criados manualmente no CineTracker. Isso permite representar corretamente reprises sem duplicar artificialmente linhas/datas.

Fixture sintética de aceitação travada no CI:

- 3.078 títulos
- 2.318 filmes
- 760 séries
- 949 registros de filme -> 1.312 visualizações
- 11.747 registros de episódio -> 14.904 visualizações
- 16.216 visualizações totais
- 533 séries não iniciadas na Watchlist
- 227 séries com histórico
- 1.312 itens em Assistir mais tarde
- 0 registros de histórico descartados

## Sincronização e segurança

- Web e Android importam para a mesma conta Supabase e compartilham os dados.
- Uma nova importação substitui apenas dados originados de importações anteriores.
- Decisões manuais do CineTracker continuam tendo prioridade sobre estados importados conflitantes.
- Metadados TMDB já existentes não são sobrescritos por dados incompletos do Bingers.
- Não há limpeza geral da biblioteca nem reset de dados do usuário.

## Estabilidade

- A camada global v97 permanece desativada no runtime final.
- O núcleo funcional v95 continua sendo a base ativa.
- Navegação HOTFIX12, seleção separada de `library.csv` e `watches.csv`, proteção do file picker mobile e autenticação/session recovery permanecem ativos.
- Android continua totalmente embutido no APK, sem fallback remoto e sem WebViewAssetLoader.
