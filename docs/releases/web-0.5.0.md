# CineTracker Web 0.5.0

## Paridade com Android

Esta versão leva para a Web as mudanças funcionais da Android 0.0.50 que não dependem de APIs nativas.

## Alterações

- Marcação inteligente de episódios com confirmação para marcar episódios anteriores da mesma temporada.
- Ordenação de `Acompanhando` por atividade recente.
- Atualização imediata da interface após alteração de progresso.
- Disponibilidade de streaming no Brasil usando TMDB Watch Providers.
- Reforço de Descobrir em três colunas compactas.
- Preservadas Home/Acompanhando sincronizados e marcação do próximo episódio.

## Diferença intencional

Notificações continuam exclusivas do Android.

## Validação

A versão só deve ser considerada validada após deploy real e teste no ambiente publicado.
