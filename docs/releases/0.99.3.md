# CineTracker Web 0.99.3

**Data:** 2026-08-27  
**Plataforma:** Web desktop  
**Android:** permanece publicado em `0.99.2.3` / `versionCode 9923` e não faz parte desta release.

## Objetivo

Corrigir a navegação Web desktop e tornar a área Descobrir reativa sem remover os recursos acumulados das versões 0.99.1/0.99.2.

## Correções principais

- Sidebar canônica limitada a Home, Descobrir, Perfil e Configurações.
- Histórico removido defensivamente de Sidebar/mobile-nav; pedidos legados de rota `history` redirecionam para Perfil.
- Nova camada `patch-v097-v0993-nav-pre.js` carregada antes do gate capture legado de 0.99.2 para receber primeiro os cliques de navegação e das pílulas do Descobrir.
- Handlers explícitos para tabs `Pra Você`, `Em Alta`, `Mais Aguardados`, `Mais bem avaliados`, `Calendário` e filtros `Geral/Séries/Filmes`.
- Diagnóstico de cliques, `window.error` e `unhandledrejection` em `window.__ct0993Diagnostics`.
- Nova camada final `patch-v098-v0993-web.js`, depois do anti-freeze FIX2, para reconciliação visual idempotente, hit-area/pointer-events e rodapé Web 0.99.3.
- `Pra Você` recebe fallback orientado quando não existe título elegível: atualizar recomendações ou importar/sincronizar dados.
- Cache Web rotacionado para `ct-web-0.99.3`.

## Recursos preservados

Continuam presentes Perfil 0.99.1, Home Séries/Filmes 0.99.2, Pull-to-Reveal, quick mark, LRU, sincronização de lançamentos, Bingers, backup, hardening de `profile_id`/`media_kind`, cinegrafia e detalhes legados.

## Arquitetura da correção

A camada de clique 0.99.3 precisa carregar **antes** de `patch-v095-v0992-fix.js`, pois essa camada antiga possui listener `window` em capture com `stopImmediatePropagation`. A camada visual/final 0.99.3 carrega **depois** de `patch-v096-v0992-unfreeze.js`.

Ordem relevante:

1. `patch-v097-v0993-nav-pre.js`;
2. `patch-v095-v0992-fix.js`;
3. `patch-v096-v0992-unfreeze.js`;
4. `patch-v098-v0993-web.js`.

## Versionamento

- package Web: `0.99.3`;
- cache: `ct-web-0.99.3`;
- rodapé: `CineTracker • v0.99.3`;
- backend permanece lógico `0.99.2`;
- Android permanece `0.99.2.3` / `9923`.

A divergência de versão é deliberada: esta unidade de correção foi solicitada exclusivamente para navegador Web desktop.
