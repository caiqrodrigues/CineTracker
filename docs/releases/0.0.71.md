# CineTracker Android 0.0.71

Correções de estabilidade observadas na validação em vídeo da 0.0.70.

- reduz disputa entre patches antigos do runtime Android removendo módulos intermediários redundantes da sequência carregada;
- Home e Assistir deixam de usar observer + intervalo contínuos para atualizar próximos episódios;
- gráfico do Perfil recebe restauração estável quando desaparecer após navegação/rerender;
- opções Carrossel, Grade e Lista deixam de ficar expostas e passam para um filtro de exibição recolhido;
- remove animações/transições dos principais cards para reduzir tremor visual;
- mantém carregamento resiliente de episódios e notas individuais por episódio;
- mantém deduplicação de streaming e filtro estrito do Descobrir;
- build Android 0.0.71, versionCode 71.

Validação visual final depende de instalação em aparelho real.
