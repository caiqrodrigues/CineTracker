# CineTracker Android 0.0.82

Nova versão oficial baseada exatamente no conjunto final aprovado da 0.0.81.

- mantém o layout aprovado de Início, Descobrir, Perfil, Histórico e Configurações;
- gráfico do Perfil com 7 dias visíveis, hoje centralizado, navegação até 10 dias anteriores e abertura dos itens vistos por dia;
- Histórico com capa do filme/série e nome do episódio quando aplicável;
- reboot e cache de metadados TMDB para capas, títulos, notas e episódios;
- reforço de sincronização com o banco após alterações de estado;
- pré-carregamento de dados, histórico e imagens para reduzir loading e tornar trocas de abas mais fluidas;
- versão oficial Android 0.0.82 / versionCode 82.

Versão Web correspondente: 0.5.6.
