# CineTracker Android 0.0.64

Correções observadas após a validação visual da 0.0.63.

- Remove repetição/acúmulo de notas nos cards de séries e na área `Em dia`.
- Compacta cards de acompanhamento/continuidade para reduzir espaço vazio.
- Padroniza `Assistido`: estado neutro por padrão e destaque verde somente quando visto/clicado.
- Em séries em andamento, o detalhe passa a refletir `Acompanhando` em vez de oferecer Watchlist de forma contraditória.
- Remove `Carregando perfil...` residual quando o Perfil já possui gráfico/conteúdo disponível.
- Consolida a área de notas do detalhe para evitar duas apresentações diferentes do mesmo título.
- Preserva o filtro estrito de Descobrir e a deduplicação de provedores de streaming.
- Configurações exibe `CineTracker Android • build 0.0.64`.

Build esperada: `cinetracker-android-0.0.64-debug.apk`.

A versão somente será considerada validada após instalação e teste no aparelho real.
