# CineTracker Android 0.0.81

Versão final aprovada para uso.

- navegação estável e troca de abas fluida;
- pré-carregamento de dados principais, histórico e capas ao abrir o app;
- cache de metadados TMDB para reduzir buscas repetidas;
- reboot de capas e metadados preservando TMDB ID como referência principal;
- sincronização reforçada após marcação de episódios e atualização de progresso;
- nota individual de episódio e abertura do detalhe do episódio;
- Perfil com estatísticas consolidadas, Watchlist separada entre séries e filmes e gráfico diário;
- gráfico com 7 dias visíveis, hoje centralizado, 3 dias para cada lado e consulta de até 10 dias anteriores;
- clique em cada dia do gráfico para abrir os itens assistidos naquela data;
- Histórico com capa de filme/série e nome do episódio para séries;
- uma única versão oficial exibida no aplicativo;
- validação de sintaxe dos módulos finais antes do build;
- APK publicado pela release android-v0.0.81 quando o GitHub Actions concluir com sucesso.

Versão Web correspondente: 0.5.5.
