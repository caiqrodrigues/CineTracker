# CineTracker Android 0.0.67

Build consolidada das correções mais recentes do runtime Android.

- corrige o desalinhamento de versão entre Gradle e MainActivity;
- carrega o módulo `ct56.js` no runtime;
- adiciona recuperação para loaders presos em Assistir, Descobrir, Histórico e Perfil;
- preserva o estado visual de `Assistido` após marcação;
- limpa metadados/notas duplicados;
- corrige mensagens residuais de temporadas e Perfil;
- mantém Descobrir estrito e streaming deduplicado;
- Configurações exibe `CineTracker Android • build 0.0.67`.

Build esperada: `cinetracker-android-0.0.67-debug.apk`.

A versão só será considerada validada após instalação e teste no aparelho real.
