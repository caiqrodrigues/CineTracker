# CineTracker Android 0.0.63

Build de publicação das correções introduzidas na 0.0.62.

## Incluído

- restauração automática do gráfico do Perfil quando um rerender o remove;
- botão `Assistido` neutro/apagado por padrão e verde somente quando o estado visto está persistido;
- normalização dos metadados dos cards de `Continuar assistindo`;
- limpeza de carregamentos residuais fora de contexto;
- preservação do filtro estrito de Descobrir;
- preservação da deduplicação de provedores em `Onde assistir`;
- marcador de build `0.0.63` em Configurações.

## Build

- `applicationId`: `com.cinetracker.app`
- `versionCode`: `63`
- `versionName`: `0.0.63`
- APK esperado: `cinetracker-android-0.0.63-debug.apk`
- Release esperada: `android-v0.0.63`

## Validação

A versão só deve ser considerada validada após instalação e teste em aparelho real. Compilação/publicação não equivale a validação funcional.
