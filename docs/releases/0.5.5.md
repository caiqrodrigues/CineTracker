# CineTracker Web 0.5.5

Versão final aprovada para uso.

- interface final aprovada nas prévias interativas;
- navegação consolidada sem controladores duplicados;
- Perfil com estatísticas principais, gráfico diário antes das estatísticas extras e Histórico abaixo;
- gráfico com 7 dias visíveis, hoje centralizado, 3 dias para cada lado e consulta de até 10 dias anteriores;
- clique no dia do gráfico para abrir o conteúdo assistido naquela data;
- Histórico enriquecido com capa do filme/série e nome do episódio quando aplicável;
- cache de metadados TMDB e prefetch de capas para reduzir carregamentos repetidos;
- reboot de TMDB para capas, nomes e notas, mantendo TMDB ID como chave preferencial;
- pré-carregamento de mídia e histórico na inicialização;
- sincronização de estado e re-render após atualizações;
- verificações automáticas de sintaxe e presença das funções finais antes do build.

Android correspondente: 0.0.81.
