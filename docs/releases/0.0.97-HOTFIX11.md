# CineTracker 0.0.97 HOTFIX 11

Reliable Bingers import and account synchronization on top of the stable HOTFIX10/v95 runtime.

## Dual CSV import
- Web and Android now expose two independent file selectors: `library.csv` and `watches.csv`.
- On Android the files can be chosen one at a time, avoiding unreliable multi-select behavior from document providers.
- ZIP and JSON remain available as alternative single-file imports.
- CSV reader accepts UTF-8 BOM and comma, semicolon or tab delimiters.
- A preview is mandatory before any database write.

## Synchronization
- Import writes to the authenticated user's shared Supabase account.
- After a completed import the importing client reloads cloud state.
- Web and Android can refresh the shared state through **Sincronizar agora**.
- Returning to the app/site, regaining focus or connectivity performs a throttled refresh.
- Ordinary actions such as Assistido and Watchlist do not trigger a full UI rebuild, preserving HOTFIX10 fluidity.

## Data integrity
- Re-import deletes only rows created by an earlier Bingers import.
- Native CineTracker history is preserved.
- Manual media overrides remain higher priority than imported state.
- Existing/manual episode progress is not overwritten by imported progress.

## Stability
- Stable v95 core and HOTFIX10 navigation remain active.
- `patch-v068-v097.js` remains disabled.
- No global MutationObserver or periodic polling was added.
- Android remains fully embedded with no automatic Vercel fallback.

## Validation
- Existing HOTFIX10 navigation/action/preview regression suite passed.
- Web tested with sequential selection of two separate CSV files.
- Test fixtures include BOM + semicolon CSV and tab-separated CSV.
- Preview verified before backend calls.
- Full `begin -> library_batch -> watches_batch -> finish` import flow verified.
- Cloud refresh after import verified.
- Exact embedded Android HTML passed the same dual-CSV and sync tests.
- Every Android inline script compiled successfully.
- Signed APK package, signature and embedded runtime verified before release.
