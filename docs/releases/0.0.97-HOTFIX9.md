# CineTracker Android 0.0.97 HOTFIX 9

P0 stability recovery. No database rollback and no user-data reset.

## Stability strategy
- Keeps the authenticated startup/session recovery that fixed the black screen and infinite login.
- Ships the proven v0.0.95 feature core as the active UI runtime.
- Temporarily removes the broad `patch-v068-v097.js` overlay from the shipped Web and Android HTML.
- Does not delete the v97 source code; it is only excluded from the production runtime until it can be rebuilt safely.
- Removes the obsolete v97 MutationObserver guard because the observer layer itself is not shipped.
- Rotates the Web service-worker cache namespace to prevent stale HOTFIX8 resources from surviving.

## Preserved
- Supabase authentication and session recovery.
- Home, Discover, History, Profile and primary navigation from the stable core.
- Search, TMDB integration, detail screens, episode progress, backup/restore and v95 profile behavior.
- Existing Supabase data, history, library, overrides and preferences.
- Android embedded authoritative runtime with no automatic Vercel fallback.

## Validation gates
- Clean startup in real Chrome.
- Accepted login in real Chrome.
- Every primary navigation tab is clicked in real Chrome.
- UI-thread soak must stay responsive with zero browser errors.
- The exact HTML embedded in Android runs through the same real-browser navigation stability test.
- Every Android inline script is syntax-compiled.
- APK package, versionCode, versionName and signature are verified before release.
