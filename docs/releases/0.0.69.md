# CineTracker Android 0.0.69

Correções desta versão:

- corrige notificações antigas/repetidas: o backlog atual vira baseline na migração e não é reenviado;
- remove o worker imediato executado a cada restauração da sessão; notificações passam a ser verificadas pelo worker periódico único;
- deduplica eventos por identidade canônica persistente, usando mídia/temporada/episódio/data quando disponíveis;
- corrige temporadas que ficavam presas em `Carregando episódios...`;
- adiciona retentativa com timeout para consulta de episódios;
- exibe a nota TMDB de cada episódio individual quando disponível;
- mantém estado Assistido de cada episódio e botão de nova tentativa em falhas transitórias;
- atualiza build Android para 0.0.69 / versionCode 69.

Validação em aparelho real ainda é necessária após instalação do APK.
