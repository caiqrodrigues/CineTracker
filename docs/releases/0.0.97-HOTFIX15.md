# CineTracker 0.0.97 HOTFIX 15

HOTFIX15 fecha duas falhas de transporte reproduzidas em aparelho e navegador reais sem iniciar a 0.0.98.

## Web desktop e mobile

- Corrige o `Failed to fetch` ao confirmar a importação do Bingers.
- A Edge Function `ct-import-bingers-user` agora responde ao preflight CORS `OPTIONS` antes da validação JWT.
- Respostas da função incluem `Access-Control-Allow-Origin`, `Access-Control-Allow-Headers` e `Access-Control-Allow-Methods` compatíveis com `Authorization`, `apikey`, JSON e o cliente Supabase.
- A semântica HOTFIX13 permanece: `plays`, 533 séries não iniciadas/Watchlist, WatchLater separado, 0 descarte silencioso, ratings/comentários/lists ignorados.

## Android

- O importador não depende mais do clique do `<input type=file>` do WebView para abrir o seletor.
- No APK, o painel mostra botões nativos explícitos para `library.csv`, `watches.csv` e ZIP/JSON.
- O seletor Android usa `*/*` sem `EXTRA_MIME_TYPES`, evitando que gerenciadores de arquivos OEM ocultem CSVs classificados com MIME inesperado.
- O slot escolhido é persistido antes de abrir o seletor.
- O arquivo selecionado é copiado para armazenamento privado temporário do app.
- Se a Activity/WebView for recriada, o CineTracker retorna automaticamente para Configurações e restaura o arquivo no importador.
- Compatibilidade com o chooser WebChromeClient permanece como fallback.

## Arquitetura preservada

- núcleo v95 estável;
- overlay global v97 continua desativado;
- Android embutido em `assets/hotfix5/index.html`;
- `loadDataWithBaseURL` preservado;
- sem WebViewAssetLoader;
- sem fallback remoto;
- autenticação/session recovery preservados;
- nenhuma limpeza geral de dados ou decisões manuais.
