# CineTracker Android 0.0.54 — Recovery

Esta versão volta à arquitetura funcional da 0.0.49 e carrega somente `ct41.js + ct47.js + ct48.js + ct49.js + ct54.js`.

Correções: marcação inteligente de episódios anteriores; Home/Continuar assistindo com rolagem horizontal reforçada e abertura da série; botão Voltar interno; Descobrir em três colunas; Acompanhando reordenado por atividade recente; atualização de progresso/estatísticas ao reabrir Perfil; bloco Onde assistir para streaming/compra/aluguel no Brasil e data de cinema para filmes quando disponível.

A camada `ct54.js` é aditiva: falhas nas consultas extras não substituem a interface base por mensagens de erro. CI valida sintaxe dos módulos, compilação Gradle e package `com.cinetracker.app`. Teste visual em aparelho permanece pendente até confirmação do usuário.
