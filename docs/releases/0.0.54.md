# CineTracker Android 0.0.54 — Recovery build

Esta versão parte diretamente da tag `android-v0.0.49`, última base confirmada pelo usuário como funcional. Ela não usa os runtimes 0.0.50, 0.0.51, 0.0.52 ou 0.0.53.

## Base carregada

- `ct41.js`
- `ct47.js`
- `ct48.js`
- `ct49.js`
- `ct54.js` apenas como camada final mínima

## Correções adicionadas

- marcação inteligente de episódios: ao marcar um episódio posterior, pergunta se os anteriores da mesma temporada já foram vistos e permite marcá-los automaticamente;
- Home / Continuar assistindo com gesto horizontal reforçado e card clicável para abrir a série;
- botão Voltar do Android retorna primeiro para episódio/série/tela interna anterior antes de sair;
- Descobrir força 3 cards compactos por linha sem substituir o carregamento de dados original;
- Acompanhando reordena pelos campos de atividade mais recentes retornados pelo backend, sem substituir a tela se a consulta adicional falhar;
- progresso marcado usa as RPCs já utilizadas pela base 0.0.49; o Perfil volta a consultar os dados atualizados ao ser aberto;
- ficha de filme/série recebe bloco `Onde assistir` com provedores do Brasil; filmes também exibem data de estreia em cinema quando disponível no TMDB.

## Estratégia de recuperação

Nenhuma das consultas adicionais desta camada substitui o conteúdo funcional da 0.0.49 por telas de erro. Em falha de enriquecimento, a interface base permanece disponível.

## Validação

O CI valida sintaxe dos cinco módulos carregados, compilação Gradle e `applicationId=com.cinetracker.app`. Teste visual/interativo em aparelho continua pendente até confirmação do usuário.
