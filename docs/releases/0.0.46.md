# CineTracker Android 0.0.46

## Objetivo

Release focada em duas garantias: atualização por sobreposição da APK anterior e notificações reais para lançamentos relevantes ao usuário.

## Atualização sem desinstalar

- Mantém `applicationId` `com.cinetracker.app`.
- `versionCode` passa para `46` e `versionName` para `0.0.46`.
- O workflow usa obrigatoriamente a mesma chave persistente `cinetracker-debug-signing-v1`.
- Se a chave persistente não estiver disponível, a build falha em vez de gerar uma chave nova. Isso evita APK incompatível com atualização sobre a versão já instalada.

## Notificações Android

- Permissão `POST_NOTIFICATIONS` adicionada para Android 13+.
- Canal nativo `Lançamentos e episódios`.
- WorkManager executa verificação periódica em segundo plano, com frequência de 1 hora.
- A sessão Supabase autenticada do WebView é sincronizada com a camada nativa via `CineTrackerNative`.
- Eventos elegíveis:
  - filme da Watchlist/WatchLater cuja data de estreia é hoje;
  - próximo episódio com exibição hoje de série marcada `InProgress`.
- Cada evento tem chave de deduplicação persistente para não repetir a mesma notificação.

## Banco

Migration `cinetracker_due_notifications_v046` adiciona a RPC autenticada `cinetracker_due_notifications()`.

## Interface móvel

O runtime `ct46.js` mantém as correções visuais combinadas para Descobrir/Tempo de Tela e é carregado por último no Android.

## Validação

Esta release não deve ser considerada validada somente por compilar. É necessário confirmar no aparelho:

1. instalação da 0.0.46 diretamente sobre a versão anterior, sem desinstalar;
2. concessão da permissão de notificações;
3. execução dos layouts móveis combinados;
4. recebimento de uma notificação real em um evento elegível.
