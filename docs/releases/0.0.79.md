# CineTracker Android 0.0.79

Correções focadas em estabilidade e consistência do Android:

- remove módulos legados conflitantes do runtime ativo;
- interrompe o looping de atualização na Home e em Assistir;
- mantém apenas uma linha canônica de progresso de série: `Temporada X • Episódio Y • vistos/total • Faltam N episódios`;
- remove a linha de progresso adicional dos cards do Histórico;
- mantém uma única versão oficial no rodapé de Configurações;
- reduz o orçamento de pré-carregamento e libera o WebView rapidamente sem bloquear a interface;
- substitui a navegação encadeada por uma navegação única com trava curta contra cliques concorrentes;
- recria o gráfico de Perfil acima do Histórico sem depender dos módulos antigos de gráfico;
- amplia o filtro do Descobrir para considerar acompanhamento, overrides/Watchlist e histórico real, em todos os filtros renderizados;
- versionCode 79 / versionName 0.0.79.

Validação automática: sintaxe dos módulos ativos, build Gradle, assinatura, package id e versionName.
