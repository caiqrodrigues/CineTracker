# Validação — CineTracker v0.99.2 FIX

## Evidência visual recebida antes do FIX
- [x] Vídeo Web no navegador Android analisado: a UI ainda carregava partes legadas.
- [x] Prints Web analisados: sidebar duplicava Perfil/Configurações e mantinha Histórico legado.
- [x] Perfil exibiu erro real `Falha ao sincronizar Perfil: days is not defined`.
- [x] Produção observada ainda exibia rodapé `CineTracker • v0.99.1`; portanto a primeira 0.99.2 não foi considerada publicada.
- [x] Usuário informou que navegação funcionava no navegador Android, mas botões não funcionavam no navegador desktop; o conflito foi rastreado a listeners capture legados em `document` com `stopImmediatePropagation`.

Essas evidências invalidam qualquer marcação anterior de “release funcional concluída” baseada apenas em presença de arquivos/markers.

## Correções do FIX
- [x] Criado `patch-v095-v0992-fix.js` como última camada do runtime.
- [x] Navegação autoritativa movida para `window` capture, antes dos listeners de `document`.
- [x] `ct0992Navigate`, `ct991Navigate` e `ct98Navigate` rebindeados para a mesma rota final.
- [x] Reconciliação de sidebar/mobile-nav para somente Home, Descobrir, Perfil e Configurações.
- [x] Binding global corrige o crash `days is not defined` do Perfil 0.99.1.
- [x] Wrapper central de `sbApi` injeta `profile_id` autenticado em POSTs de `watch_history`, `episode_progress` e `media_overrides` quando ausente.
- [x] Wrapper central infere `media_kind` em inserts legados de `media` quando ausente.
- [x] Cabeçalhos expansíveis de Séries/Filmes/Favoritos recuperados com visões completas.
- [x] Rodapé final autoritativo mantido em `CineTracker • v0.99.2`.

## Implementação e banco
