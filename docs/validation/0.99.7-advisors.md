# Supabase advisors após migration 0.99.7

**Data:** 2026-08-28

A migration `v0997_profile_payload_local_activity` foi seguida por execução dos advisors de segurança e performance.

## Resultado da função nova

Nenhum advisory novo aponta para `cinetracker_profile_payload_v0997`. A função é `SECURITY INVOKER` por padrão, teve `PUBLIC EXECUTE` revogado e `EXECUTE` concedido apenas a `authenticated`.

## Avisos preexistentes mantidos separados da 0.99.7

Segurança:
- `_cinetracker_build_payload` com RLS sem policy;
- funções antigas SECURITY DEFINER expostas a anon/authenticated;
- leaked password protection desativada.

Performance:
- FKs sem índice em `watch_history.media_id` e `watch_play_events_v0994.media_id`;
- policies antigas com `auth.uid()` reavaliado por linha;
- índices não usados;
- índices duplicados de `watch_history`.

Esses débitos não foram introduzidos pelo RPC 0.99.7 e não são alterados nesta release para evitar ampliar o escopo de uma correção de UX.
